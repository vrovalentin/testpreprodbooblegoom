# Тест-кейсы: boobl-goom.ru (preprod)

Кейсы описаны без привязки к инструменту, чтобы их можно было перенести в Codeception.
Стенд: https://preprod.boobl-goom.ru (HTTP-авторизация). Город по умолчанию: Владивосток.

Статусы автоматизации: ✅ есть автотест · ⏳ ждёт тестовый аккаунт / отключение капчи · ✋ только вручную

Общие предусловия для всех кейсов: открыт стенд, закрыта плашка cookie («Согласен»), подтверждён город («Да, верно»).

## Что нужно для кейсов ⏳

1. Тестовый аккаунт (e-mail + пароль) на препроде.
2. Капча на препроде отключена или есть тестовый ключ Яндекс SmartCaptcha.
3. Решение по заказам: можно ли доводить до создания, и кто их удаляет. До решения тесты останавливаются перед финальным подтверждением.
